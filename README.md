# KICKS

AI-powered sneaker recommendation web app.

## Prerequisites

- Node.js 20.x LTS or newer

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Starts the Vite dev server (default: http://localhost:5173).

## Production build

```bash
npm run build
```

Outputs to `dist/`.

## Routes

| Path | Page |
| --- | --- |
| `/` | Home Page |
| `/results` | Results Page |
| `/comparison` | Comparison Page |
